# 本机照片复核

本工具在本机打开原图和自动标注，可逐张删除误检、补框、记录复核者和说明。不会上传图片或改动原图。

双击结果目录的“复核照片.command”，会启动本机服务并打开浏览器。保留启动窗口，关闭服务后页面就不能继续读取原图。也可以在结果目录运行：

```sh
/opt/miniconda3/bin/python scripts/review_server.py
```

在浏览器打开 http://127.0.0.1:8768 。选择实验组、照片序号和显示比例。原始像素可用于检查虫体叠靠。

1. 检查整张图，而不只看现有框；删除误检及倒影，补上漏检。
2. 框应一只一框，并核对左右株上、其他位置和无法确认类别。明确重叠而不能确定虫数时，不用一个框冒充精确个体数，在说明中写清原因。
3. 填写复核者和说明后保存。记录追加到“人工复核追加记录.jsonl”，含原图路径、SHA256和坐标。

自动框只是候选，打开或保存页面不自动证明计数正确。未解决的“疑似”应保留，不能并入左右主计数。复核记录目前不会自动覆盖Excel或图表；整批复核完成后，应先审查记录、界定可纳入帧，再重新积分生成新版本。连续照片不能作为独立实验重复。

工具仅监听127.0.0.1。在运行窗口按Ctrl+C可结束。
